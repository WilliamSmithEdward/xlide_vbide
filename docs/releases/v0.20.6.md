Patch release for editing code while paused and for the shared analyzer update.

- Fixes issue #71: ordinary statement edits made during VBA break mode reach the native module, survive switching tabs, and are used by Continue. Edits that require a debugger reset remain visible until the user chooses **Reset and apply**; XLIDE blocks running or saving older native code while such an edit is pending.
- Adds spacing around the Reset confirmation text and buttons.
- Updates the bundled analyzer to xlide_vscode v11.1.0 (`8f64c2ce8d4c7104c7aa3559da0e98b6c178303e`), including more responsive incremental diagnostics and corrections to reference-change and runtime findings.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
