Patch release for the Locals panel.

- Expanding an object no longer hides the variables below it. Before, expanding a Workbook, or `Me` at the top of a class, took every local after it out of the panel until it was collapsed.
- Expanding and collapsing are faster. A Workbook's members show in about 200 milliseconds instead of most of a second, and an expanded object no longer slows every update while the break lasts.
- A member far down an expanded object, such as a Workbook's Worksheets, now expands when its arrow is clicked. Before, the click did nothing.
- Expanding a Worksheet can still start Outlook when Outlook has no profile. The editor's own Locals window reads every property of the sheet, MailEnvelope included, the moment it is expanded.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
