Patch release fixing IntelliSense and diagnostics for referenced COM type libraries.

- `RegExp` and `Scripting.FileSystemObject` offer members of their own classes when their libraries are referenced, rather than unrelated completions.
- Enum constants from referenced libraries, including Scripting Runtime's `ForAppending`, resolve without an undeclared-variable error.
- The engine uses the type libraries installed on the host for references it does not already model. An unreadable library does not block analysis of the project's other references.
- Includes the analyzer pinned to `303790100e62d4fae3986aa2001fbe9d2d19e809` (xlide_vscode v11.0.1).

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
