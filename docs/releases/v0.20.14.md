Patch release for the editor's Enter and arrow keys.

- Enter makes a new line and Up and Down move the caret in the code editor again (#103). Since 0.20.12 the Immediate pane's entry line had claimed all three keys in every editor, so they ran its commands instead.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
