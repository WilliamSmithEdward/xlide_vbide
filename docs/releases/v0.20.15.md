Patch release for the analyzer's phantom errors.

- The analyzer no longer falls out of step with the editor (#105). When the VBE respaced a line the editor had written, and the module was then shown again, the analyzer kept the older text. Every later keystroke landed in the wrong place in its copy, so it reported errors that were not in the code, and a rename computed from that copy wrote it into the module. The copies now stay in step, and if they ever disagree the editor's text is taken again.
- Writing a module after something outside the editor added or removed lines in it, such as a macro or another add-in, could leave a stale copy of a line and drop the last one. The module is read again first now.
- Double-clicking a control in the form designer no longer loses typing in that form's code that had not been written yet.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
