Patch release for scrolling while stopped, and for keys the menus promised but the host takes.

- Scrolling while stopped at a breakpoint stays where you put it. The editor used to bring the stopped line back into view every few hundred milliseconds, so a scroll away jumped back (#88). The stopped line is still revealed once, when the stop happens.
- Rename Symbol is Ctrl+Shift+R. The context menu showed F2 for it, and F2 opens the Object Browser as it does in the native editor (#90). The menus and the command palette no longer show F2, Ctrl+F2, F8 or Shift+F8 beside editor commands those keys can never reach, since the host takes them for the Object Browser, Step Into and Step Over.
- The browser's own shortcuts are switched off inside the editor. They were at the browser's defaults, so Ctrl+R reloaded the surface, Ctrl+P offered to print it, Ctrl+Shift+I opened its developer tools and Ctrl+wheel zoomed it.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
