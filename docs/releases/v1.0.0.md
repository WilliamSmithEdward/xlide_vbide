Version 1.0.0. The editor now updates itself and shows lenses above procedures, and the analyzer moves to v11.2.11.

- Updates come to you. A few seconds after the editor opens, once per Office session, it asks this repository's releases for a newer one and offers it with its notes: Install now, Release notes, Skip this version, Not now. Install downloads xlide-setup.exe, checks its length and SHA-256 against the digest GitHub publishes for the file, and starts it. Check for updates is also on the wrench menu and in About xlide, and the check on open can be turned off in Settings. This is the first release that carries the updater, so 1.0.0 itself is installed by hand.
- Lenses above procedures. Run test and Debug test sit over every `@xlide-test` procedure, and every procedure carries a count of the places that use it across the project. A click on the count opens Find All References. One switch in Settings turns them off.
- Text in the Changes pane, the import and export dialog and the Source Control pane holds WCAG AA contrast in both themes. Coloured and dimmed text there was being dimmed a second time.
- Ships analyzer v11.2.11, ten releases on from v11.2.1. It reports more of what the VBE refuses, so code that showed no problems before can show some now:
  - A `ReDim` without bounds, an `Erase` of one element of an array, and `Name` without `As`.
  - A `For` without `To`, a `Declare` without `Lib`, and `DefDec`.
  - An argument passed to `Beep`, and a standard module's name used as a type, such as `Dim h As Helpers`.
- A call with too few arguments is reported in the VBE's words, "Argument not optional".
- The Date statement, as in `Date = #1/2/2026#`, is no longer reported as an undeclared variable under Option Explicit.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
