Patch release improving pane layout customization and restoring defaults.

- Dock a tool pane into a separate group beside the code editor, even when that side already has panes. Immediate can sit below code and above Problems, Locals, and Watch, with an independent resize divider. The arrangement survives Office restarts.
- Adds a **Restore default pane layout** toolbar button with an “Are you sure?” confirmation. Cancel, Escape, and backdrop dismissal preserve the current layout; explicit confirmation restores and saves pane defaults while retaining code and editor settings.
- Gives confirmation modals shared 16px padding. The restore-layout explanation wraps inside a bounded card, with inset buttons and readable spacing in narrow windows.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
