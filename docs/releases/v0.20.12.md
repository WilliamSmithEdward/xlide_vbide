Patch release for the Immediate pane and the explorer's sheet names.

- The Immediate pane's entry line completes as the code window does: the member list after a dot, the names in scope as you type, quick info and parameter info (#97). It answers in the scope the line runs in. While stopped at a breakpoint that is the stopped procedure, so its local variables are offered; otherwise it is the module on screen. Enter runs the line and Up and Down walk the history, unless the completion list is open.
- The explorer shows a worksheet's or chart's tab name beside its code name, as the native Project Explorer does: `Sheet4 (Sheet1)`. A tab renamed in Excel shows once you are back in the editor (#98).

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
