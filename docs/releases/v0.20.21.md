Patch release for the Rename Symbol box (#128), and two checks the analyzer could not make here before.

- A name typed into Rename Symbol is readable in the dark theme. It was drawn in black on the dark box, which showed only once typing cleared the selected name (#128).
- A declaration that takes a name its sheet already has is reported, such as `Public Sub Calculate()` in a worksheet's module. The analyzer is now told whether each document module is a worksheet, a chart sheet or the workbook.
- A type from a library the project does not reference is reported as the VBE reports it, such as `Dim c As ADODB.Connection` without a reference to ActiveX Data Objects. Adding the reference clears it without editing the module.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
