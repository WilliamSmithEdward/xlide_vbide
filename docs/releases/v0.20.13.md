Patch release for the code window's Object and Procedure lists.

- Each code editor has the native code window's two lists above it (#101). On the left are (General) and the objects the module can handle events of: a sheet's Worksheet, ThisWorkbook's Workbook, a class's Class, a form and each of its controls, and every WithEvents variable. On the right are (General)'s procedures, or the chosen object's events, with the handled ones in bold.
- Picking an object goes to its default event's handler, such as Worksheet_SelectionChange or a button's Click, and picking an event goes to that handler. Either is written first when the module does not have it. The handler is declared as the VBE declares it, parameters included, and placed where the VBE places it.
- The lists follow the caret, so they always name the procedure you are in.
- The explorer's Sort list draws its open list in the editor's colours, like the other lists.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
