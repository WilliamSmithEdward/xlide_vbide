Patch release with a dark-mode editor fix and release security improvements.

- Fixes the editor context menu in Dark Mode: its background is opaque and its labels and shortcuts have readable contrast.
- Corrects reading version 4 compound files and rejects damaged files rather than reading incorrect sectors.
- Adds the dedicated ClamAV and YARA-X malware gate, daily security scanning, and weekly proposals for pinned YARA Forge rule updates.
- Strengthens dependency auditing and release packaging. Release assets include security and malware reports and signed provenance.
- Includes the analyzer pinned at `535af19a2a62b36107383b3037d30c656b064b0c` (v10.14.6) and synchronizes the editor's vendored spec helpers to that pin.

Download **xlide-setup.exe** for the Windows installer. The accompanying reports describe the scans of this release commit.
