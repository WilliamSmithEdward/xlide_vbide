Patch release for debugger parity, and the analyzer moves to v11.1.4.

- Ctrl+Shift+F8 steps out, as in the native editor. It used to run to the cursor (#83).
- Ctrl+F9 sets the next statement. Ctrl+Shift+F9 clears all breakpoints (#82).
- In break mode, drag the yellow arrow in the margin to the line that should run next. A click on the arrow still toggles a breakpoint (#82).
- Breakpoints follow what the editor does with them. Typing on a breakpointed line keeps its breakpoint, and deleting the line removes it, from the margin as well as from the editor. Before this the margin kept a dot the editor had dropped, and F9 on it either set a breakpoint nothing drew or raised "Breakpoint not allowed on this line" (#84).
- A compile error takes you to it. After the error box closes, the module that holds the error opens with the offending token selected, as the native editor does, and the message is repeated in a notice (#86).
- The yellow arrow sits centred on its line when it shares the line with a breakpoint dot. The two glyphs used to merge into one shape drawn half a line low.
- Ships analyzer v11.1.4.
