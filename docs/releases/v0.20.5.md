Patch release correcting editor context menus and updating the shared analyzer.

- Fixes the transparent editor context menu in Dark Mode and gives the menu an opaque surface, readable text, and a visible border in both dark and light modes.
- Makes hover selection visible in both themes and uses the same selection color in the editor and Explorer context menus.
- Updates the bundled analyzer to xlide_vscode v11.0.3 (`1854476f8545ad49e772baec5eaff93da0f72131`), including reference-aware Scripting and RegExp models and corrected argument checks for quoted Optional defaults.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
