Patch release for bookmarks (#111).

- Bookmarks are on the toolbar. One Bookmarks button opens Toggle, Next, Previous and Clear All when you rest the pointer on it, click it, or tab to it. The native Edit toolbar that carried them stays hidden.
- All four bookmark commands are on the editor's right-click menu, with their keys: Ctrl+Alt+K, Ctrl+Alt+N, Ctrl+Alt+P and Ctrl+Alt+Shift+K.
- A new Bookmarks pane lists every bookmark with its module, line and the line's text. Click a row to go there, press Delete to remove it, or clear them all from the pane's bar. A closed module's bookmarks stay listed. With several files open, a filter narrows the list to one file.
- Pane tabs that no longer fit their dock scroll with arrows at each end, like the editor tabs.
- A native toolbar left floating is now hidden with the docked ones. Its buttons acted on the code window under the editor, so a bookmark set there never showed.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
