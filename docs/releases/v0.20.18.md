Patch release for the light theme (#114).

- The whole editor follows Windows' light mode now, not only the code: the explorer, the panes, the toolbar, the dialogs, the menus, the Object Browser and the title bar. Before, a light Windows got light code inside a dark editor.
- Settings has a Theme choice at the top of the list: Use system (the default, which follows Windows' app mode and changes with it), Light, or Dark.
- Every light surface is held to WCAG AA contrast. The code editor's light line numbers and the Immediate line's hint were too faint and are darker now.
- Dark is unchanged.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
