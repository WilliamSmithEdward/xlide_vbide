Patch release for typing in documents with AutoSave on, and the analyzer moves to v11.1.9.

- In a workbook with AutoSave on, typing no longer hitches. Each pause in typing wrote the line back to VBA, which dirtied the workbook and set off a cloud save on Excel's own thread, and a completion asked for meanwhile waited behind it (#94). With AutoSave on, a line is now written when the caret leaves it, as the native editor commits a line. Pastes, formatting and fixes are written straight away as before, and running, saving or switching modules writes everything first.
- The explorer lists a module's Enums and Types beside its procedures, each kind with its own icon. A Sort picker in the explorer's header orders a module's members as in code, by name, or by kind, and a property's Get, Let and Set sit together under every order (#92).
- Ships analyzer v11.1.9.
- The release workflows name the exact versions of the actions they pin.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
