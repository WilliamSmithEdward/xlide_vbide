Patch release preserving XLIDE preferences across Office sessions and applications.

- Fixes issue #76: pane layouts survive a full Office restart and are shared across Excel, Word, Access, and PowerPoint. Open and closed panes, active pane tabs, dock positions, tab order, split proportions, and sizes are retained.
- Preserves code-editor group geometry, the Source Control divider, and editor and Object Browser window bounds and maximized state. Restored windows fit an available monitor.
- Unifies settings, sync choices, and UI state under one per-user AppData persistence procedure. Atomic saves merge changed fields so concurrent Office sessions preserve unrelated preferences. Existing settings retain their format and location.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
