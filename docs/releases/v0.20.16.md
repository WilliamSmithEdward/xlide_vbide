Patch release for how the editor reads after a line is committed.

- A line you leave now reads the way the VBE stored it, as the native editor shows it. The VBE respaces operators (`x=1+2` becomes `x = 1 + 2`), closes a string left open at the end of a line, writes `1.0` as `1#` and `?` as `Print`. The editor used to keep the text as typed until the module was shown again. The line you are typing on is never changed under you.
- A closer you type over the one Smart Enter wrote no longer leaves two. Typing `endif` above the `End If` that Enter added after `If ... Then` now leaves a single `End If`, with the caret on the line below. A closer the code needs, such as one ending an inner block, is kept.

Download **xlide-setup.exe** for the Windows installer. The accompanying security and malware reports describe scans of this release commit and installer.
